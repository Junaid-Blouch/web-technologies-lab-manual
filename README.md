## 📚 Overview

This repository contains a complete lab manual for the **Web Technologies** course.  
It covers:

- Internet vs WWW, web browsers vs web servers
- HTML fundamentals (headings, tables, colors, lists, forms, multimedia)
- XML basics (syntax, well‑formed documents)
- CSS styling (inline, internal, external), selectors, box model, positioning
- JavaScript (variables, functions, events, DOM manipulation)
- Final project: **Personal Resume Webpage** using HTML & CSS

All experiments include objectives, theory, code examples, and screenshots of outputs.
